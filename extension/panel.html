    Safer capture checklist
    • Open DevTools in a separate window (⋮ → Dock side → Undock): docked DevTools changes the page size, which a site can notice.
    • Keep “Disable cache” off in the Network panel.
    • Scroll the chat at a normal pace. Do not reload it to capture again; use Capture from Network log.
    • Keep sessions short and take breaks. A new session starts from the dashboard.
    • Stop if TikTok shows a verification check, a rate-limit message or any warning.
    • Use an account you can afford to lose. Manual import of saved files stays the safest path.
