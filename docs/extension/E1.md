## Проверка

- `npm run check`: 95 тестов, 95 pass, 0 todo; lint и build без ошибок.
- `npm run test:e2e`: 3/3 (понадобилось `npm install` — в основной копии не был установлен `playwright-core`; lockfile не изменился).
- Новые тесты: возобновление после сброса бюджета и удержание новых захватов, `Retry-After`, `capture_disabled`, операции с задержанными элементами, состояния слушателя и навигация с чужого сайта на TikTok, heartbeat только при включённом захвате, словарь статусов. Серверный интеграционный тест проверяет `TOKEN_REJECTED` и то, что отклонение аватара не меняет `devtools.state`.
- Popup и панель проверены в браузере через страницы с подставным `chrome.*`: список задержанных элементов, двухшаговый `Discard`, лента событий; ошибок в консоли нет. Вид пока старый — редизайн в E5.

## Что требует живой проверки (E6)

- Порядок и содержимое `inspectedWindow.getResources()` на реальной странице TikTok Messages: если документ не определится, слушатель работает в режиме `site not confirmed`, а не блокирует захват.
- Реальные заголовки ответов CDN (`image/awebp`, `octet-stream`) на тестовом аккаунте.
