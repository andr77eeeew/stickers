# Этап E5 — единый дизайн

Состояние: 27 сентября 2026 года, выполнен. Правила оформления и приоритет статуса в шапке — [SPEC.md](SPEC.md) §3–4.

## Главный вывод

Popup и панель DevTools переведены на систему Specimen Catalogue: те же токены, что у dashboard, те же компоненты (brand mark, pill статуса, кнопки, строки статуса, предупреждения) и те же тексты. Расширение называется **Sticker Workspace Capture**, версия 3.0.0. Поведение захвата и доставки не менялось: правки касаются только страниц, значков и текстов.

## Что сделано

1. **Токены.** `extension/shared/tokens.css`: светлые значения из `docs/redesign/stage1/tokens.json` под именами переменных dashboard (`--text-2`, `--ok`, `--problem`…), плюс производные (`--border-strong`, границы тонов, `--accent-text`, `--on-accent`). Тест сверяет цвета, радиусы, focus-ring, высоту контрола, длительности и шрифты с `tokens.json` и с `:root` в `frontend/src/index.css`.
2. **Тёмная палитра панели** (`:root[data-theme="dark"]`) переопределяет каждый цвет. Тест проверяет контраст ≥ 4.5:1 в обеих темах: основной и вторичный текст, акцент, успех, предупреждение и ошибка на всех фонах и своих подложках, белый текст на кнопках. При подборе не прошла только одна пара — hover акцента в тёмной теме (4.19:1), он сделан темнее акцента.
3. **Popup (360 px, всегда светлый):**
   - шапка — brand mark, `Sticker Workspace · Capture` и pill общего статуса;
   - переключатель **Capture from TikTok DMs** (`role="switch"`);
   - строки статуса (DevTools, Local server, Queue, Session) с точкой тона;
   - до двух предупреждений (`inline-alert`) и последнее событие;
   - **Held captures** — карточки с **Save file** / **Discard** (второй клик — красный **Confirm discard**) и **Retry all**; коды причин переведены в текст;
   - **Settings** свёрнуты; без токена этот блок сам раскрывается как шаг **Connect to Sticker Workspace** с тремя шагами и кнопкой **Connect**;
   - «How capture works» свёрнут.
4. **Панель DevTools:**
   - те же компоненты; `panelTheme.js` до первой отрисовки ставит тему по `chrome.devtools.panels.themeName`, а без DevTools API — по системной теме;
   - шапка с pill и переключателем, четыре плитки статуса (2 колонки на узкой панели);
   - лента сессии карточками с миниатюрой на шахматном фоне и ссылкой **Open in library**;
   - Pacing с предупреждениями и памяткой, Activity;
   - с 900 px — две колонки.
5. **Общий статус в шапке** — `StatusText.describeOverall`, порядок как у pill dashboard: `Not connected` → проблема сервера → `Verification check` → `Capture off` → `Session limit` → `Delivery failed` → короткий текст слушателя (`Watching`, `DevTools closed`…). Короткие тексты совпадают с dashboard (`LISTENER_SHORT` экспортирован и сверяется тестом).
6. **Иконки:**
   - outline lucide (ISC, текст лицензии в `shared/icons.js`), встраиваются в разметку через DOM API без `innerHTML`;
   - значок расширения 16/32/48/128 — brand mark dashboard (sparkles на тёмном квадрате); на 16 px звезда залита, мелкие детали убраны;
   - PNG рисует `scripts/render-extension-icons.js` через Chrome; тот же значок у панели DevTools;
   - цвета badge уже брались из токенов, теперь это проверяет тест.
7. **Переименование:** manifest `Sticker Workspace Capture` 3.0.0 с `icons` и `action.default_icon`; вкладка панели в DevTools осталась короткой — **Sticker Capture**. Подсказка в dashboard и README обновлены.
8. **Доступность:**
   - у полей есть `label`, у токена — `aria-describedby`;
   - `aria-live` только у итогов: pill (`role="status"`), сообщение popup, итог разбора журнала Network;
   - предупреждения больше не объявляются при каждом опросе;
   - видимый focus-ring 3 px `#B8A7F5`, `prefers-reduced-motion` отключает переходы;
   - при ошибке в настройках фокус переходит на нужное поле.
9. **`Setup required`** (сервер ещё не настроен) теперь `pending`, а не `problem`: до подключения это ожидаемое состояние.

## Ограничения

- Что `themeName` в реальном DevTools возвращает `dark` и при теме «System preference», нужно подтвердить в E6. При смене темы Chrome перезагружает DevTools, поэтому отдельный обработчик не нужен.
- Chrome почти не показывает значок панели DevTools; он задан для полноты.
- Высота popup в Chrome ограничена 600 px, в проблемном состоянии список прокручивается.
