# Этап E0 — страховочные тесты

Состояние: 26 сентября 2026 года, выполнен. Код расширения не менялся.

## Что добавлено

- `test/extension/safety-invariants.test.js` — 9 инвариантов границы безопасности:
  - manifest: только проверенные ключи; нет `content_scripts`, `web_accessible_resources`, `externally_connectable`, `content_security_policy`, `optional_permissions`; permissions ⊆ {`storage`, `alarms`}; host permissions только loopback;
  - код: нет XHR/WebSocket/EventSource/sendBeacon, `eval`, `new Function`, `inspectedWindow.eval/reload`, `chrome.scripting|debugger|tabs|webRequest|cookies|downloads…`, MutationObserver и URL-литералов вне loopback;
  - `fetch` только в `background.js` (доставка на `${settings.serverUrl}/api/…`, где `serverUrl` проходит `normalizeServerUrl`) и в загрузчике собственной политики;
  - `importScripts` и HTML-страницы подключают только файлы расширения, без inline-скриптов и фреймов.
- `test/helpers/extensionHarness.js` — запуск `background.js` и `devtools.js` в `vm` с in-memory `chrome.storage/alarms/action/runtime/devtools`, очередью вместо IndexedDB и `fetch`, который отказывает и записывает нарушение для любого адреса вне loopback и ресурсов расширения.
- `test/extension/background.test.js` — 10 сценариев поведения и 4 контракта ошибок:
  - доставка: одно обращение, Bearer, только 5 полей payload, без query и токена в теле, `credentials: 'omit'`, `redirect: 'error'`;
  - отказ по политике до очереди (аватар, несовпадение байтов);
  - дедуп в очереди, backoff и retry-alarm, недоступный сервер, блокировка 4xx и `Retry blocked`, отсутствие токена без обращения к серверу;
  - первый запуск: токен сгенерирован, захват выключен; статус не раскрывает токен;
  - DevTools: `getContent()` вызывается только для ответа-стикера — не для JSON API сообщений, аватара, 404 или при выключенном захвате; cookie из запроса не попадает в payload.
