## Проверки

- `npm run check`: 39/39 тестов, ESLint без предупреждений, сборка Vite. Bundle: CSS 24.1 kB (gzip 5.7 kB), JS 211.0 kB (gzip 66.9 kB) против baseline 21.2 / 182.5 kB — рост за счёт новых экранов, lucide-иконок и инспектора.
- Unit-тесты модели: состояния, фасетные счётчики, сортировки, ограничение страницы, 1000-element fixture (в DOM одна страница), Telegram check для наследной и новой записи, скрытие абсолютных путей, пользовательские/системные теги, round-trip URL и отказ от недопустимых значений.
- **Реальная библиотека** (Browser, только чтение, 114 записей): 105 Ready + 9 Needs action = 114 (2 not converted, 3 failed, 3 output missing, 1 over limit — наследный WebM на 257 KB при лимите 256 KB). Deep-link `?id=…&status=action`, фильтры, пустой поиск, Health (33 пункта хранилища: 1 / 3 / 8 / 21 / 0), popover, открытие панели импорта. Ошибок загрузки ресурсов нет. База не изменялась: 114 записей, время изменения файла прежнее.
- **Геометрия** (iframe нужной ширины, т. к. эмуляция панели не опускается ниже 600 px): горизонтального overflow нет на 320 / 375 / 390 / 640 / 768 / 1024 / 1280 / 1440 px. Первый ряд: 198 px на 1440×900 (цель ≤ 200), 236 px на 375–390 px (цель ≤ 280); в первом экране 24 плитки на 1440 и 12 на 390.
- **Песочница** (`127.0.0.1:3002`, пустая библиотека во временной папке, ingest выключен): drop PNG + TXT → 1 imported, TXT пропущен, auto-convert → Ready; повторный drop → Duplicate с ID; теги сохранены вместе с `import:`; 4-секундный MP4 импортирован, сконвертирован из инспектора (WebM 179 KB / 256 KB, 3.0 s), полоса Needs action появилась и исчезла по WebSocket; Escape сначала закрывает редактор, затем инспектор с возвратом фокуса; сохранение из редактора; архив через диалог; остановка сервера → «Updates paused», данные остаются видимыми.

## Найдено по ходу

- Статическая конвертация занимает около 14 s, сохранение из редактора — около 22 s даже для маленьких файлов: `compressStaticSticker` всегда делает ~7 кодирований с `effort: 6`. Это поведение сервера до этапа 3; вынесено в отдельную задачу.
- Нормализация импорта ограничивает анимацию 3 секундами (60 кадров из 4-секундного ролика), поэтому окно нарезки в инспекторе появляется только у записей, где длительность источника больше 3 s.

## Не входит в этап 3

Batch/job контракт и центр задач (этап 4), новый редактор, детальные проблемы хранилища, список и проверка архивов (этап 5), паки и экспорт (этап 7).

## Приёмка

Принято без изменений: плотность по умолчанию (9 колонок на 1440 px, плитка ~142 px), формулировка `Not recorded (converted by an earlier version)` для наследных записей и постоянная полоса Needs action, пока есть проблемы. Следующий шаг — этап 4.
